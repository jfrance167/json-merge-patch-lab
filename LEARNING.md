# Learning

Null depends on position. Inside an object patch it removes a member, while a nonobject root patch replaces the complete target. Null inside a replacement array, including a field inside an array element, is literal data. An empty object patch can preserve an object or replace a scalar/array/null with an empty object; absent nested deletion can create an empty nested object.

Transformation does not grant authority to modify a resource. This model receives values and returns evidence; it has no service/target-file path. Operation-looking values are still ordinary merge values. Exact name comparison and typed changed detection keep normalization, pointer interpretation and false/zero equality from entering silently.

Input/tree caps do not cap report bytes when snapshots and ASCII escaping repeat evidence. The admitted16118-byte fixture produces94123 output bytes and is stopped by the65536 cap. This is measured report amplification, not exponential merge growth. Conservative union caps and redundant byte/scalar limits are documented rather than presented as impossible passing boundary tests.

Type identity avoids metaclass equality hooks, and admitted-builtin cloning avoids deepcopy hooks. Write-count comparisons also need exact types: a faulty sink returning3.0 for three characters passed a simple equality check. The preserved regression now requires an exact int; bool/None/float results fail. Weak-worker labels were reviewed against sources, not promoted to oracles.
