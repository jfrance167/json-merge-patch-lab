# Security model

Only inert supplied synthetic trees are supported. No actual target resource/file/configuration is modified; report output is a separate exclusive fresh artifact. No external reference, operation path, API/service, private document, credential, production policy, dynamic code or network target is supported. Reports intentionally include supplied target/patch/result evidence.

Full raw/native admission precedes schema and merge; identity checks avoid caller equality/hash/iteration/copy hooks, cycles fail and aliases count per occurrence. Bounded parser/recursion/tree work and escaped report-size checks are defined in PLAN.md. Direct parsed-object input cannot recover encoded numeric spelling. Result union limits are defensive and not claimed reachable overflow cases. No complete-standard/floating-point JSON conformance, host isolation, hostile filesystem-race protection, atomic delivery or concurrent-input guarantee.

Windows CPython3.13.7 is the tested environment. Runtime/demo Bandit has one documented B105 false-positive skip; tests/operator harnesses are outside that scan. Targeted source secret-signature checking is not a full history audit. Review is self-review; no hosted checks/security eligibility/new repository were assessed. Jake retains publication/merge/deployment decisions.
